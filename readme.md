# 🌍 Projeto: Conheça Busan

Este é um **projeto de treino desenvolvido durante os estudos na Rocketseat**, com o objetivo de praticar conceitos fundamentais de **HTML e CSS** na construção de uma página web.

## 📌 Sobre o projeto

A página apresenta informações sobre **Busan**, destacando alguns pontos da cidade e simulando o layout de uma **landing page de viagem**.

O foco principal do projeto foi **praticar estruturação de páginas e estilização com CSS**, aplicando conceitos aprendidos durante os estudos.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3

## 🧠 Conceitos praticados

Durante o desenvolvimento do projeto, pratiquei diversos conceitos importantes de front-end, como:

- Estruturação semântica com **HTML**
- Organização do layout utilizando **container**
- Uso de **classes e seletores CSS**
- **Responsividade básica**
- Estilização de imagens
- Controle de **margin e padding**
- Alinhamento e **justificação de texto**
- Aplicação de **cores e tipografia**

## 🎯 Objetivo

O objetivo deste projeto foi **consolidar conhecimentos iniciais de desenvolvimento front-end**, praticando a criação de layouts e a organização do código.

## 📚 Aprendizado

Esse projeto fez parte da minha jornada de aprendizado em desenvolvimento web e contribuiu para melhorar minha compreensão sobre:

- Estrutura de páginas web
- Organização de estilos CSS
- Boas práticas iniciais de desenvolvimento
